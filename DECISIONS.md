# Журнал архитектурных решений

## 2026-09-27: Репозиторий как общая рабочая доска
**Решение:** использовать четыре файла в `mpaykin1/scratch-chain-reaction`; каждому агенту — собственная ветка `ai/**` и PR в `main`. Статусы задач проверяются машинно. Не заменять существующий `AGENTS.md` в отдельном репозитории `World_server`.

**Причина:** два агента должны работать над одной кодовой базой, не перезаписывая незакоммиченный код друг друга. `IN_REVIEW` не равен `DONE`; подтверждённые проверки обязательны.

**Альтернативы:** прямые push в `main` и ручное копирование между чатами не обеспечивают атомарное ревью. GitHub Actions без модельного runner не считается связью с Qwen.

## 2026-09-27: Сохраняем реальную архитектуру рендера и симулятора
**Решение:** оставить WebGL 2.0 в `cinematic/render-effects.mjs` как надстроенный слой эффектов, 2D-ассеты как основной фон, чистый симулятор `cinematic/chain-engine.mjs`. Следующие эффекты используют `ecology`, `energy`, `water` из текущего GLSL; не вводим несуществующий `uEcology`.

**Причина:** текущие `fitCanvas` и `createAdaptiveQuality` уже ограничивают разрешение и динамически управляют нагрузкой. Полный 3D и заявленные 60 FPS требуют отдельного внедрения и измерений.

## 2026-09-27: Генерируемая сводка без фиктивных обновлений
**Решение:** `node scripts/sync-agent-context.mjs` заменяет только ограниченный маркерами раздел в `CONTEXT.md`. Генерация детерминированна, без дат от времени запуска и без автопуша в `main`. Рабочие ветки `ai/**` получают автообновление через workflow, а PR — проверку.

**Причина:** исходный пример с `echo >> CONTEXT.md` постоянно добавлял дубликаты и мог спровоцировать гонки/циклы push.

## 2026-09-27: Двуязычные тексты отдельно от игровой экономики
**Решение:** пять новых действий Джинна сначала оформляются как проверяемый RU/EN словарь с допустимыми дельтами ресурсов, не меняя `getGenieChoices()` и формат сохранений.

**Причина:** нарратив должен быть готов для интеграции, но новые численные эффекты нельзя объявлять живой механикой до отдельного PR с тестами. Интеграция — CR-103.
