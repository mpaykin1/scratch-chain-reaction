# Паспорт проекта «Цепная реакция»

## Проекты

- Эта доска управляет `mpaykin1/scratch-chain-reaction` (`main`); общий мир и Telegram-интеграция требуют отдельного PR в `mpaykin1/World_server` (`master`). Перед любым изменением получать свежий HEAD; SHA в старых сообщениях может устареть.
- Демо: 2D cinematic UI с собственным WebGL 2.0 слоем эффектов, сценарий водного кризиса и отдельный Scratch/TurboWarp player. Полноценный 3D-рендер пока не является реализованной возможностью этого слоя.
- Логика: `cinematic/chain-engine.mjs` — детерминированные ресурсы, история и отложенные последствия; `cinematic/idea-parser.mjs` — ограниченная обработка текста; `cinematic/main.mjs` — управление состоянием и локальным сохранением.
- Графика: `cinematic/render-effects.mjs` — WebGL 2.0 эффекты и CSS fallback; `cinematic/quality.mjs` — DPR ≤2, длинная сторона буфера ≤1080 px; `cinematic/adaptive-quality.mjs` — динамическое качество.

## Проверка и публикация

`npm run test:agents` проверяет доску и пакет нарратива. `npm run test:cinematic` и `npm run test:cinematic:browser` проверяют движок и интерфейс (для браузерного теста нужен локальный HTTP-сервер и Playwright). Публикация и ссылка для тестирования — только после точной проверки SHA, браузерных desktop/mobile тестов и покрытия экрана >85%.

## Ограничения

GitHub Actions в данном PR автоматизирует обновление файлов доски и контроль их согласованности. Он **не** запускает Qwen, не использует его API и не утверждает, что кто-либо проверил продукт на реальном iPhone 11. Для настоящей автономии нужен отдельный авторизованный runner и секреты GitHub Actions.
