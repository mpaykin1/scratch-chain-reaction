Цепная реакция · собственный проигрыватель

Это оригинальный Scratch-проект с собственным локально размещённым движком TurboWarp Scaffolding. Скрипты, анимация и пять вариантов выбора работают внутри Scratch.

На iPhone для запуска без адресной строки: открой страницу в Safari → Поделиться → На экран Домой.

Если хочется оригинальную кинематографическую компоновку, открой экран HTML-игры.

Движок: TurboWarp Scaffolding, MPL‑2.0. Исходный код движка. Наши доработки: GitHub проекта.
