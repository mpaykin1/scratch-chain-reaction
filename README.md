# Цепная реакция — анимированная Scratch 3

Полностью самостоятельный проект Scratch 3 с реальными PNG/SVG-костюмами, **не картинка и не HTML-имитация**. Запускается в официальном Scratch через импорт `.sb3`, а на GitHub Pages через совместимый проигрыватель TurboWarp.

## Полноэкранный режим на телефоне

- На телефоне сайт открывает игроку весь доступный браузерный viewport; отдельный [игровой экран](./play.html) убирает страницу-обёртку. Кнопка ⛶ включает Fullscreen API там, где браузер его поддерживает.
- На iPhone открой опубликованную игровую страницу в Safari → «Поделиться» → «На экран Домой» и запусти значок с домашнего экрана. Режим PWA `standalone` скрывает интерфейс Safari (но не системный статус-бар).
- **Сцена Scratch пока 480×360 (4:3)**: сам контейнер может занимать 100% экрана, но реальное игровое поле на вертикальном телефоне сохраняет пропорции. Чтобы игровой мир заполнял больше 85% площади портретного экрана без обрезки пяти кнопок, нужна отдельная вертикальная компоновка фонов и спрайтов и адаптация размера сцены, а не CSS-растяжение.
- Текущий iframe загружает внешний TurboWarp. Для автономного размещения движка можно собрать игру через [TurboWarp Packager](https://github.com/TurboWarp/packager) (исходный код MPL-2.0), разместить HTML на своих GitHub Pages и убрать зависимость от внешнего iframe.
- `python -m unittest -v test_mobile_shell.py` — статическая проверка мобильной HTML-оболочки. `node test_mobile_viewport.mjs` — проверка с браузером Playwright, скриншоты и фактическая доля игрового canvas. Перед публикацией требуется проверка на реальном iPhone.

## Что сделано

- Старт: только сухая пустошь, **без вулкана**, по ней бредут люди.
- 5 игровых вариантов: город, лес, энергия, вулкан и собственная идея.
- Злой Джинн вылезает из диалогового окна, имеет 4 анимационных кадра.
- Движутся человечки, пыль, дым, вулканические частицы и лопасти ветряков.
- После каждого хода видны новые объекты, динамические показатели ресурсов и последствия.
- Джинн предлагает 4 компромиссных решения и пятый свободный ответ.
- Ресурсная модель с накоплением дефицита: электричество, вода, пища, экология, бюджет и население. После кризиса можно продолжать игру.
- Нет серверных API, токенов, платных зависимостей; для генерации файла достаточно Python 3 + Pillow, если исходные арты уже извлечены.

## Исходный код и редактирование

1. `python extract_assets.py` — извлечёт отдельные PNG-ассеты из `chain-reaction.sb3` в `assets/`.
2. `python build_animated.py` — соберёт новый `chain-reaction-animated.sb3` с исходными анимациями и игровыми скриптами.
3. `python test_release.py` — запустит статические проверки структуры и комплектности.

`asset_prep.py` — дополнительный исходный пайплайн обработки изображений, если доступны исходные широкоформатные арты, созданные для проекта. Для штатной пересборки исходные изображения не требуются: они уже включены в `.sb3`.

Важное уточнение: свободный текст обрабатывает встроенная детерминированная модель Scratch по распознаваемым ключевым словам, **это не подключённая LLM**. Никаких тайных API-вызовов или облачных расходов нет.
