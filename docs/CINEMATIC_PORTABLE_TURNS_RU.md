# Продолжение мира и перенос сохранений

Cinematic-игра теперь допускает **пустой ход**: кнопка ⏭ выполняет очередь отложенных событий и проверяет кризисы без строительства. Движок `chain-engine.mjs` остаётся единственным источником игровых состояний, а `main.mjs` управляет интерфейсом. Один ход воспроизводится при одинаковом состоянии.

**Экспортировать мир** сохраняет JSON с ресурсами, построенными объектами, очередью отложенных эффектов и историей причин. **Импортировать мир** восстанавливает его в другом браузере без сервера и API-ключей. Неверный файл не меняет состояние; размер импорта ограничен 120 КБ. Импорт можно отменить через «Отменить ход» до перезагрузки страницы.

Новый модуль `portable-save.mjs` включён в offline precache, поэтому импорт/экспорт и пустые ходы доступны после первого успешного подключения в PWA. Формат использует существующую версию `serializeWorld`/`restoreWorld`.

**Проверки:** `npm run test:cinematic` (чистый движок, импорт и реплей), `npm run test:cinematic:browser` (мобильный/десктопный экран, аудио/WebGL, offline, загрузка файла JSON, восстановление после reload). Живая публикация проверяется отдельным workflow, включая точное совпадение нового модуля.
