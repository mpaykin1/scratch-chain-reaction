# Первый реальный графический компонент World Server в «Цепочке»

Скопирован **без переписывания генератора** модуль `shared/world-shape-library.mjs` из
`mpaykin1/World_server` на точном SHA `bca976629b0662e70b6d6e3d1092994fdef054a9`,
исходный blob `76498800492076e0bf10b1d1ee0a449392bed6da`.
Оба репозитория принадлежат одному владельцу; никаких сторонних моделей или лицензий не заявлено.

Тонкий визуальный адаптер рендерит настоящие воксели оригинального генератора дома
и деревьев в изометрический Canvas. Он реагирует исключительно на `worldStateUpdate`
и не рассчитывает игровые ресурсы, не создаёт локальную копию серверного мира и
не меняет исходную графику cinematic. На мобильном рисует меньше деревьев,
поддерживает DPR не выше 2 и перерисовывает только при изменении состояния/размера.

После объединения серверного PR #329 и браузерного PR #15 визуальная сцена получает
то же серверное `placed` через уже существующий `render-ui.mjs`.

Проверка: `node --test test/world-server-graphics.test.mjs`; затем полные CI,
точная опубликованная сборка и мобильный browser smoke. Сама интеграция двух
клиентов, реальные снимки iPhone и видимость >85% этой веткой **не доказаны**.
