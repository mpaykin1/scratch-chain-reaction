# Cinematic: архитектура игрового цикла

Cinematic-демо — отдельный лёгкий браузерный клиент. Scratch `.sb3` и self-hosted player не изменяются этим рефакторингом.

| Модуль | Ответственность |
| --- | --- |
| `cinematic/chain-engine.mjs` | Детерминированная симуляция: ресурсы, строительство, анализ известных идей, очередь событий, выбор Джинна, следующий ход, сериализация. Без DOM и сети. |
| `cinematic/game-ui.mjs` | События интерфейса, отображение мира, история, undo, управление вкладками и анимацией людей. |
| `cinematic/game.css` | Все прежние адаптивные стили, включая portrait/landscape и reduced-motion. |
| `cinematic/enhancements.mjs` | Подключение WebGL-эффектов, звука по согласию пользователя и регистрации service worker. |
| `cinematic/scenario-engine.mjs` | Отдельный детальный сценарий водного кризиса; не подменяется cinematic-моделью. |

## Инварианты

1. Один выбор или одна идея = один ход. Кнопка «Следующий ход» продвигает мир даже без строительства. На каждом ходе исполняются отложенные последствия и проверяются кризисы.
2. События содержат номер хода, текст, изменение ресурсов и `parentId`. Их можно увидеть в меню, воспроизвести и экспортировать.
3. Джинн выбирает текущий дефицит среди энергии, воды, еды и экологии. Для него предлагает **четыре детерминированно перемешанных компромисса**: два рискованных, один переносящий дефицит и один более сбалансированный. Это **фиксированная модель**, а не подключённая LLM.
4. Свободный текст распознаёт известные механизмы: город, лес, энергия, вулкан, ферма, орошение, очистка. Неизвестные и явно отрицаемые идеи не списывают бюджет и не создают выдуманные последствия.
5. Состояние хранится локально (версионный JSON); undo держит до 20 снимков за сеанс. При недоступном localStorage экспорт JSON остаётся доступным.
6. `worldStateUpdate` и `worldAction` сохраняют интеграцию с графическими и звуковыми модулями. Цикл анимации людей останавливается в фоновой вкладке и при reduced-motion.
7. Движок не знает про canvas, CSS, API-токены или сеть. Клиент не исполняет введённый текст как HTML.

## Проверки перед выпуском

`node --test test/chain-engine.test.mjs test/cinematic-extensions.test.mjs test/scenario-engine.test.mjs` — повторяемость состояний, очередь, динамические решения, границы ресурсов и неизвестные идеи.

`node qa_release.cjs` после запуска статического HTTP-сервера — 390×844, 844×390 и 1440×900: пять стартовых кнопок, видимые объекты, переходы, следующие ходы, undo, сохранение после reload и работа эффектов. Отдельный сценарий воды тестируется `test/scenario-ui.cjs`.

Известное ограничение: произвольное естественное описание событий (например, действия дракона) пока не интерпретируется. Для него потребуется валидируемый серверный AI-планировщик с подтверждением событий детерминированной моделью. Обещать произвольную симуляцию без такого планировщика нельзя.
